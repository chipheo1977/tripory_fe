<feature>
  <name>parseLocationInput</name>
  <files>packages/itinerary/src/domain/location-input.ts, packages/itinerary/src/domain/location-input.test.ts</files>
  <behavior>
Thứ tự thử, dừng ở mẫu đầu khớp:
0. Trim; rỗng → `empty`. Tọa độ trần regex `^\s*(-?\d{1,3}(?:\.\d+)?)\s*,\s*(-?\d{1,3}(?:\.\d+)?)\s*$` → lat, lng; `createWgs84Coordinate` null → `out-of-range`; source 'coordinates', place {null,null}.
   - '10.7769, 106.7009' → (10.7769, 106.7009); '10.7769,106.7009' ok; '-33.8,151.2' ok; '91, 10' → out-of-range; '10,7769 106,7009' → invalid; '10.7769' → invalid.
1. Thêm `https://` nếu chuỗi bắt đầu bằng `www.`, `maps.`, `google.`, `maps.app.goo.gl/`, `goo.gl/`. Tách host/path/query bằng chuỗi (regex `^https?:\/\/([^/?#]+)([^?#]*)(\?[^#]*)?`), host hạ chữ thường.
   - host `maps.app.goo.gl` → `short-link` (url = chuỗi đã chuẩn hóa có https). host `goo.gl` và path bắt đầu `/maps/` → short-link; `goo.gl/abc` → invalid.
2. Host Google hợp lệ: `^(?:www\.|maps\.)?google\.(?:com|[a-z]{2}|com\.[a-z]{2}|co\.[a-z]{2})$` và (host bắt đầu `maps.` hoặc path bắt đầu `/maps`). Không hợp lệ → invalid (vd `https://evil.com/maps/@10,10,15z`).
3. `!3d<lat>!4d<lng>` ở bất kỳ đâu trong path/query (lấy cặp CUỐI) → source 'place-data'.
4. Path `/maps/(place|search)/<lat>,(+|%20)?<lng>` → 'path'. Ví dụ thật: `https://www.google.com/maps/search/29.996966,+68.748251?entry=tts` → (29.996966, 68.748251).
5. Query `query=`, `q=`, `ll=`, `destination=`, `center=` có giá trị tọa độ (decode `%2C`, `+`) → 'query'. Vd `https://www.google.com/maps/search/?api=1&query=47.5951518%2C-122.3316393`, `https://maps.google.com/?q=10.77,106.70`, `…/maps/@?api=1&map_action=map&center=10.77,106.70`. `query=Ch%E1%BB%A3` (tên) không tính.
6. `@lat,lng(,zoom z)?` trong path → 'viewport'. Vd `https://www.google.com/maps/@10.7769,106.7009,15z`.
7. Còn lại (URL Google hợp lệ không có tọa độ) → `no-coordinate`.
- Tên địa điểm (gắn vào `place` cho cả `coordinate` và `no-coordinate`): đoạn `/maps/place/<seg>/`; thay `+` → khoảng trắng; `decodeURIComponent` trong try/catch (URIError → bỏ tên); bỏ ký tự mã ≤ 0x1f và 0x7f; nếu seg là tọa độ thì bỏ; tách tại dấu phẩy ĐẦU TIÊN: name = trước (trim, ≤ 200 ký tự), address = sau (trim, ≤ 500, rỗng → null); không có dấu phẩy → address null (D-49).
   - Ví dụ thật (đích của `maps.app.goo.gl/PJdcARfqULFnpENj7`): `https://www.google.com/maps/place/Brandenburg+Gate,+Pariser+Platz,+10117+Berlin,+Germany/data=!4m2!3m1!1s0x47a851c655f20989:0x26bbfb4e84674c63` → `no-coordinate`, name 'Brandenburg Gate', address 'Pariser Platz, 10117 Berlin, Germany'.
   - `/maps/place/Ch%E1%BB%A3+B%E1%BA%BFn+Th%C3%A0nh/@10.77,106.69,17z/data=!3m1!4b1!4m6!3m5!1s0x0:0x0!8m2!3d10.7725!4d106.698!16s` → coordinate (10.7725, 106.698), source 'place-data', name 'Chợ Bến Thành', address null.
   - `/maps/place/%E0%A4%A/…` (`%` hỏng) → không ném, name null.
   - `!3d` ngoài khoảng (`!3d95!4d10`) → out-of-range.
- `formatCoordinate({ latitude: 10.77691, longitude: 106.70089 })` = '10.7769, 106.7009'.
- `isShortMapsLink(raw)` = `parseLocationInput(raw).kind === 'short-link'`.
  </behavior>
