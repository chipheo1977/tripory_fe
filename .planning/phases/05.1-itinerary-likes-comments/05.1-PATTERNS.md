## Quy ước chung (áp dụng cho mọi file mới)

- Component client: dòng đầu `"use client";`, kế đó comment tiếng Việt nêu quyết định (D-xx) và ràng buộc. Ẩn/hiện bằng prop `visible` (component tự `return null`), không `? :`/`&&` trong JSX; chọn class theo biến thể bằng bảng `Record` (mẫu `public-overview-summary.tsx` `VARIANT`). Tối đa một cấp `? :`/`&&` trong một biểu thức; nhiều hơn thì tách biến có tên hoặc early return.
- Props: `export type XProps = Readonly<{...}>;`, hẹp (không truyền cả `Comment`/`Itinerary`). Hàm thuần tách thành file `.ts` cạnh component (mẫu `overview-format.ts`, `public-format.ts`).
- Test cạnh file `x.test.tsx` / `x.test.ts`; test route/BFF dùng `// @vitest-environment node`.
- Package context: Vitest môi trường node, test thuần. Hook React và component test ở `apps/web` (jsdom), hook dựng từ factory với repository giả bằng `vi.mock("@/composition/social.client", ...)`.
- Chỉ `apps/web/src/composition/**` được import `@tripory/social/http`. `modules/**`, `components/**`, `app/**` chỉ import `@tripory/social` (type, hàm thuần) và `@tripory/social/react` (type) hoặc `@/composition/*`.
- Comment trong code là chữ thường tiếng Việt, mô tả quyết định/ràng buộc; không comment thừa.
- ESLint của `apps/web` (eslint-config-next 16, `eslint-plugin-react-hooks` 7.1) báo lỗi khi `setState` đồng bộ trong `useEffect` (`react-hooks/set-state-in-effect`) và khi ghi `ref.current` lúc render (`react-hooks/refs`); đã thử trên file mẫu ngày 2026-11-12. Hook mới phải suy giá trị lúc render (state dẫn xuất, `useSyncExternalStore`) hoặc cập nhật trong handler/callback, không trong thân effect. `packages/*` dùng `base` không có hai rule này nhưng cũng viết theo cùng cách.
- `import "server-only"` chỉ ở `composition/*.server.ts`. Phase này không thêm file server nào.

## Excerpts đã chốt (đã đọc trong phiên)

### Quy tắc phân quyền thuần (mẫu cho `canDeleteComment`)
`packages/itinerary/src/domain/permissions.ts`:
```ts
export const canEdit = (itinerary: Itinerary, viewerId: UserId | null): boolean =>
  viewerId !== null && itinerary.ownerId === viewerId;
```
Hai id cùng đi qua `parseUserId` (chữ thường) nên so `===` không sai vì hoa thường. `canDeleteComment(viewerId, authorId, ownerId)` làm y hệt.

### ACL trường tùy chọn (mẫu cho ba trường đếm và cho `author` của comment)
`dto.ts`: `author: itineraryAuthorDto.nullish()`; `mappers.ts`: `toAuthor(dto)` trả `undefined` khi thiếu hoặc hỏng (id sai, tên rỗng); `...(author === undefined ? {} : { author })`; avatar mặc định dicebear (`https://api.dicebear.com/7.x/identicon/svg?seed=tripory`) thành `null`. Ba trường đếm làm cùng kiểu: `.nullish()` và chỉ tạo `engagement` khi đủ cả ba.

### HTTP repository
`createHttpItineraryRepository(http, deps)`: mọi lệnh qua `http.send({ method, path, body, query, signal })`; body dựng từ field đặt tên cứng; phản hồi qua `dto.parse(data)` rồi mapper; `id` đã chuẩn hóa GUID; không log. `social` làm y hệt, thêm `removeComment` bắt `isApiError(error) && error.code === "Comment.NotFound"` trả `"already-removed"`.

### Hook factory và scope
`createItineraryHooks(deps)` gọi một lần ở composition (`itinerary.client.ts`); `useWriteMutation` dùng `mutationKey` + `scope: { id }` để TanStack chạy nối đuôi; callback cấp hook (`onMutate/onError/onSuccess/onSettled`) chứ không cấp `mutate(vars, {...})`. `useInfiniteQuery` mẫu `useMyItineraries`: `initialPageParam: 1`, `getNextPageParam: (last) => last.hasNextPage ? last.pageIndex + 1 : undefined`.

### Composition
`composition/itinerary.client.ts`: `const repository = createHttpItineraryRepository(bffHttp, ...); export const itinerary = createItineraryHooks({ repository, ... });`. `social.client.ts` tương tự với `createHttpSocialRepository(bffHttp)` và `createSocialHooks({ repository })`.

### Toast lỗi mutation
`composition/query-client.ts`: `MutationCache.onError` gọi `decideMutationError(error, mutation.meta?.feedback)` rồi `notify[variant](message)`. Mutation chỉ khai báo `meta: { feedback: { errorToast?, successMessage?, fallbackMessage? } }`. Mutation có xử lý riêng (gắn ô) đặt `errorToast: false`.

### Dialog xác nhận phá hủy
`delete-itinerary-dialog.tsx`: `DialogContent size="sm" initialFocus={cancelRef}`; `handleOpenChange` bỏ qua đóng khi `pendingRef.current`; `<DialogClose disabled={pending} ref={cancelRef}>`; nút `Button variant="danger" loading loadingLabel`. `DeleteCommentDialog` làm y hệt (nhãn "Giữ bình luận"/"Xóa bình luận", `loadingLabel` "Đang xóa…").

### Link dạng nút cho khách
`guest-login-button.tsx`: `next/link` + `buttonVariants({ size: "md", variant: "secondary" })`, `next = toSafeNextPath(pathname + search)`, `href = next === null ? "/login" : "/login?next=" + encodeURIComponent(next)`. `toSafeNextPath` có ở `@tripory/identity` (root export).

### Slot và keo
`PublicArticle` đã nhận `author` là node ghép sẵn ở hero; `PublicItineraryPage` nhận `recovery: ReactNode` từ `page.tsx`; `accountSlot()` là node truyền xuống `PublicItineraryView` (`account`). Slot mới đi cùng đường đó.

### Hook bọc API trình duyệt
`use-native-share.ts`: `useSyncExternalStore(subscribeNever, readSupported, readServerSupported)` với `readServerSupported = () => false`; hàm chạy API (`navigator.share`) nằm trong hook, component chỉ nhận `supported` và `share`. `useShortcutHint` làm cùng kiểu.

### Cuộn có tôn trọng reduced motion
`use-day-navigation.ts`: `section.scrollIntoView?.({ block: "start", behavior: prefersReducedMotion() ? "auto" : "smooth" })`, rồi `focus({ preventScroll: true })`. `prefersReducedMotion()` ở `modules/itinerary/ui/map/map-camera.ts` (`window.matchMedia("(prefers-reduced-motion: reduce)").matches`); `social` tự khai báo bản gọn trong `use-comments-focus.ts`.

## Shared Patterns

### Lỗi và thông báo
Mutation: lỗi có mã trong `ERROR_MESSAGES` hiện câu đó; không có thì dùng `fallbackMessage` theo ngữ cảnh (thêm ở plan 04); hết phiên im lặng (Phase 3 lo). Lỗi validate gắn ô nhập (không toast). Query đọc: không toast; trạng thái lỗi ngay tại chỗ.

### Ẩn/hiện
Mỗi trạng thái của khối comment là một component có `visible` (`CommentListSkeleton`, `CommentsEmpty`, `CommentsLoadError`, `CommentLoadMore`, `CommentComposer`, `CommentGuestPrompt`). Bản nháp: `CommentSection`, `LikeControl`, `OverviewSocialRow` nhận `visible={false}` hoặc không được dựng (factory trả `NO_PUBLIC_SOCIAL`).

### Truy cập trình duyệt
Chỉ trong hook `use-*.ts`. Component không chạm `window`, `document`, `navigator`, `localStorage`, `fetch`.
